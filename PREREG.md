# CBIO033 "miRNAs in Lung Cancer Detection" - preregistration (written and committed WITH src/run033.py, before any model is scored)
Date 2026-10-09. Real public data only, CPU only. This is a re-test of the abstract's hypothesis ("miRNAs with lower dysregulation levels convey useful information for lung cancer diagnosis") on an independent public cohort, not a reproduction of the student's own dataset (not public to us).
## Data
GEO GSE137140 (serum miRNA, 3D-Gene array, GPL21263, 2,565 miRNAs, values log2-scale, sha256 of the series matrix in data_manifest.json). Labels from "disease state": 1,566 pre-operative lung cancer (LC), 2,178 non-cancer controls (the series text says 1,774 controls; the matrix has 2,178 - we use the matrix and state the discrepancy), 180 post-operative LC (excluded from training and testing, used only in D9). Sex and age are in the matrix.
miRNA sequences: RNAcentral mirbase.fasta.gz (miRBase entries by hsa name, matched via GPL21263 miRNA_ID_LIST). Measured coverage: 2,511 of 2,565 array miRNAs map to a sequence (the rest are multi-ID probes or names absent from this release); D8 uses only mapped miRNAs.
## Known problems stated up front (found by metadata inspection before any model was scored)
(a) SITE CONFOUND: sample-title prefix is a perfect proxy for class: all LK samples are lung cancer; all controls come from other prefixes (XA 979, XB 992, PR 97, SA 80, BC 30). So cases and controls were not collected in the same cohort, and no within-cohort case/control comparison exists. (b) AGE CONFOUND: mean age LC 65.3 vs controls 50.8. (c) log2 values include a floor value for undetected miRNAs. Therefore any high accuracy here may reflect cohort/batch or age, not lung cancer biology; D4, D5 and D6 are the controls and the claim wording is set by them, not by D2.
## Method fixed in advance
Stratified 5-fold CV, seed 0, pre-op LC vs controls. Random forest: 300 trees, max_features=sqrt, n_jobs=2, seed 0, no tuning. Within each training fold only: FC = 2^(mean_log2 LC - mean_log2 control); significance = Mann-Whitney U, Benjamini-Hochberg q < 0.05. Bins: HD = significant and (FC <= 0.5 or FC >= 2.0); MD = significant and FC in (0.5, 0.9] or [1.1, 2.0); ND = FC in (0.9, 1.1) (significance not required; the abstract is ambiguous). From each bin the 50 miRNAs with the largest |AUC - 0.5| in the training fold are the features (all of them if the bin has fewer than 50, count recorded). Test fold never touches FC, significance or selection. Metrics: accuracy, balanced accuracy, AUROC, mean over folds (sample sd, ddof=1).
## Directions (all ten declared now)
D1 Curation: counts per label/prefix/sex, age summary, bin sizes per fold.
D2 Abstract re-test, leakage-free: HD/MD/ND classifiers as above. Gate "abstract pattern reproduced": accuracy HD >= 0.95, MD >= 0.90, ND >= 0.85.
D3 Selection-leakage control: same bins and top-50 chosen on ALL samples before CV. Gate "leakage matters": any bin's accuracy higher than D2's by >= 0.02.
D4 Batch/site control: (a) controls XA vs XB only (both controls, no disease): RF on all 2,565 miRNAs, 5-fold AUROC; batch effect present if AUROC >= 0.60. (b) 5-way cohort identity among controls: accuracy vs majority-class baseline. (c) HD and MD classifiers (D2 procedure) with LC against each control group separately (XA, XB, PR+SA+BC): AUROC per group; label signal "stable across control cohorts" if the range of AUROC <= 0.03.
D5 Age/sex control: logistic regression on age and sex only (5-fold AUROC); HD/MD classifiers on a 1:1 sex-matched, age-matched (|dAge| <= 3) subset (nearest-neighbor, no replacement, seed 0; matched n reported), same CV. Confound judged material if age+sex-only AUROC >= 0.80 OR the matched-subset AUROC is lower than the full-data AUROC by >= 0.05.
D6 Random-feature baseline: 50 miRNAs drawn at random from the 2,565 (10 draws, seed 0 offset by draw) with the same RF, 5-fold. MD "carries information beyond random miRNAs" only if MD AUROC exceeds the random-50 mean AUROC by >= 0.05.
D7 Threshold sensitivity (descriptive, no gate): MD edges (0.5,0.9]/[1.1,2.0) vs (0.6,0.95]/[1.05,1.67) vs (0.7,0.9]/[1.1,1.43); report accuracy and AUROC.
D8 Sequence clustering: pool the 50 HD + 50 MD miRNAs selected on all data (labelled as full-data selection; descriptive), mapped sequences only. Features: length, GC fraction, 1-mer and 2-mer frequencies, seed-region (nt 2-8) 1-mer fractions. K-means (k = 2..60, seed 0, n_init 10) on standardized features; knee = max distance to the chord of the inertia curve. Control: 20 random pools of 100 mapped miRNAs, same procedure. Gate "student's n=31 reproduced": knee in [28, 34] AND the real-pool knee outside the central 90% of the random-pool knees. If the knee is inside the random range the clustering claim is not distinguishable from any 100 miRNAs.
D9 Post-operative description: HD and MD models trained on all pre-op + controls; fraction of the 180 post-op samples predicted cancer, against the pre-op training-sample fit (descriptive; the same patients' pre-op samples may be in training, so this is not a test).
D10 Sanity and feature-count curve: (a) label-permutation control: MD classifier trained on shuffled training labels (true test labels), 5-fold, 5 permutations; sane if mean AUROC is within 0.50 +/- 0.03. (b) MD accuracy and AUROC with 5, 10, 50, 200 features.
## Claim wording fixed in advance
Whatever D2 shows, the README first line says the cohort is site-confounded and the result is NOT evidence for the abstract's lung-cancer claim, unless D4(c) stable AND D5 not material AND D6 passes. A positive D2 with failed D4/D5/D6 is reported as "classification of cohort/age, not shown to be lung cancer". Negatives reported as negatives. No hyperparameter changes after seeing scores.
## Limits
One public serum cohort; no independent external validation cohort (none known with the same platform); mapped-sequence coverage 96%; FC computed assuming log2 scale per GEO processing text; MD/HD/ND thresholds from the abstract; the student's original dataset and results are not available, so this tests the hypothesis, not the student's numbers.
